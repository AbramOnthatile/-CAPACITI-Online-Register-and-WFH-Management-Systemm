This is a Vite-powered React application for the CAPACITI Online Register & WFH Management System.

## Development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually [http://localhost:5173](http://localhost:5173).

## Production

Run `npm run build` to create a production build in `dist/`. Run `npm run preview` to serve that build locally.
